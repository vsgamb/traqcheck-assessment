# TraqCheck Candidate Management

Full-stack app for uploading resumes, extracting candidate details, requesting identity documents, and collecting PAN/Aadhaar uploads.

## Stack

**Backend:** Python, Flask, Flask-SQLAlchemy, PyPDF2, python-docx  
**Frontend:** React, Vite, Axios, React Router  
**Database:** SQLite (default file: `backend/candidates.db`)

## AI Document Requests

Document requests are generated by a custom `DocumentRequestAgent` (`backend/ai_agent.py`) using the **OpenRouter API** (free models such as `openrouter/free`). The agent builds a personalized PAN/Aadhaar request from the candidate's name and contact details, with a fallback template if the API is unavailable.

Set `OPENROUTER_API_KEY` in `backend/.env` (see `.env.example`).

## API Endpoints

| Method | Endpoint | Description |
|--------|----------|-------------|
| POST | `/candidates/upload` | Upload resume (PDF/DOCX) |
| GET | `/candidates` | List all candidates |
| GET | `/candidates/<id>` | Get candidate profile |
| POST | `/candidates/<id>/request-documents` | Generate document request message |
| POST | `/candidates/<id>/submit-documents` | Upload PAN/Aadhaar files |
| GET | `/health` | Health check |

Backend runs on `http://localhost:5002` by default.

## Setup

### Backend

```bash
cd backend
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt
cp .env.example .env
```

Edit `.env` and set `OPENROUTER_API_KEY` (get a key from https://openrouter.ai/keys).

```bash
python app.py
```

### Frontend

```bash
cd frontend
npm install
npm run dev
```

Open `http://localhost:3000` in the browser.

## Deployment

The PDF stack suggests Render, Railway, or Vercel. This is **not** a separate deliverable (deliverables are the public repo and Loom video), but you can deploy as follows:

**Backend (Render / Railway):** Root directory `backend`, start command via `Procfile` (`gunicorn`). Set env vars from `.env.example`, especially `OPENROUTER_API_KEY`. Use `DATABASE_URL` for PostgreSQL on production if needed.

**Frontend (Vercel / Netlify):** Build `frontend` with `npm run build`. Set `VITE_API_URL` to your deployed backend URL.

## Environment Variables

See `backend/.env.example`. The `.env` file is gitignored and holds your local secrets.
